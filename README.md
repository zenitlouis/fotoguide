# Fotografický zápisník

Interaktívna slovenská príručka fotografovania pre Canon EOS 100D.

Obsahuje deväť vizuálnych ťahákov, praktický kontext ku každej téme a cvičenia do terénu.

## GitHub Pages

Publikovanie zabezpečuje workflow v `.github/workflows/pages.yml`. V nastavení repozitára vyber **Settings → Pages → Source: GitHub Actions**.
